# Security Policy

## Reporting Security Vulnerabilities

The Sui Name Service (SuiNS) contracts are deployed on Sui Mainnet. We take security seriously and welcome responsible disclosure of vulnerabilities from the community and security researchers.

If you discover a security issue, please do not open a public issue on GitHub.

### Bug Bounty Program

SuiNS is covered under the official Sui Protocol Bug Bounty program on HackenProof:

- Program URL: https://hackenproof.com/programs/sui-protocol
- Scope: SuiNS smart contracts, core Move modules, and name registry protocols.
- Rewards: Paid in accordance with severity guidelines on HackenProof.

### Direct Disclosure

You can also report critical findings directly to the Mysten Labs security team:

- Email: security@mystenlabs.com

Please include a technical description of the vulnerability along with steps to reproduce or a proof of concept.
